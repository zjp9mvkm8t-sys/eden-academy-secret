RH-01
ATTENTION
SNS · 트위터 / 인스타그램 / 에브리타임
규리 실종 제보 게시글
CLUE-01: "배지 달린 애 조심해. 해부 인형 배 속 봐."
@규리를_찾아주세요 계정. 퍼펫 마스터가 댓글 실시간 응답. 마지막 카톡이 핵심 단서.
RH-02
SEARCH
HTML · 공식 홈페이지 소스코드 주석

PUZZLE DESIGN

퍼즐 유형 설계

방탈출 기본 문제 유형 7가지를 에덴 스토리에 맞게 재해석했습니다.

🔍
TYPE 01
수색 / 관찰
모든 스테이지
소품 클릭 인터랙션. 액자 뒤 팔찌, 인형 배 속 쪽지, 좌석 하단 포스트잇.
🔢
TYPE 02
개수 세기
A-04, C-02
학생회장 사진 재임 연도 세기 → 금고 비번. X 표시된 학생 번호 순서 나열.
🧬
TYPE 03
패턴 규칙
A-03, B-01
규리 노트의 해부학 기호 → 숫자 치환표. 약품 라벨과 교차 분석 시 B-3-47 확정.
🔐
TYPE 04
카이사르 암호
A-06, B-03
이동 칸수 4 확정. EDEN → IHIR. 규리 노트 암호문을 4칸 역이동하면 경로 해독.
🎨
TYPE 05
색상 치환
A-06
약품 라벨 색상 코드 매핑. 색상 순서가 숫자로 치환되어 자물쇠 번호 구성.
🧠
TYPE 06
논리 추론
A-09, C-05
수인 vs 아란 발화. 셋 중 하나만 진실 — 수인 발화 2개 중 하나는 반드시 거짓.
🧩
TYPE 07
그림 퍼즐
A-08
해부 인형 복부 지퍼 인터랙션. 규리가 숨겨둔 쪽지 → 수인 배지 = 마스터키 확정.

ENDINGS

엔딩 분기 7종

신뢰도 × 아이템 × 선택지의 조합으로 7가지 엔딩이 결정됩니다.

🌟 ENDING 1
완전 해방 엔딩
아란 신뢰 ≥ 60 + HQ 2개. 규리 구출 + 수인 폭로 + 학원 조직 붕괴.
✨ ENDING 2
진실 엔딩
아란 신뢰 ≥ 40 + HQ 1개. 규리 구출 + 수인 정체 완전 폭로.
🚪 ENDING 3
탈출 엔딩
아란 루트 + HQ 없음. 규리 구출, 탈출 성공. 에덴의 비밀은 남아 있다.
💀 ENDING 4
도덕적 패배 엔딩
C-05에서 수인 제안 수락. 서연이 에덴의 공범이 됨.
🌿 ENDING 5
생존 엔딩
C 시나리오, 선별 기준표 비공개 선택. 탈출하지만 진실은 묻힌다.
📢 ENDING 6
완전 해방 엔딩 C
C 시나리오, 선별 기준표 세상에 공개. 에덴 전체 고발.
☠️ ENDING 7

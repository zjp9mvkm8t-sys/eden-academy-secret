# 🌌 에덴 기숙학원의 비밀 (Secret of Eden) — GitHub Project Dashboard

> **에덴 기숙학원의 비밀**은 몰입감 넘치는 3D 프로시저럴 공간 탐색 시스템, 다중 엔딩 멀티 시나리오 분기, 그리고 획득 소지품 간의 유기적 연동 분석기(Active Gears Coupling Analyzer)를 내장한 **하드보일드 어드벤처 ARG 방탈출 웹 애플리케이션**입니다.

이 프로젝트는 React 18+, Vite, HTML5 Canvas API, Tailwind CSS, 그리고 Motion 패키지를 기반으로 설계되었으며, 극적인 심리 묘사와 고해상 전용 암호 해독 퍼즐을 통합 제공합니다.

## ⚡ 주요 핵심 기술 및 설계 디자인 (Key Features & Engineering)

### 1. ⚙️ Procedural Perspective 3D Engine & Live Scenery Feed (Room3DExplorer)
*   **리얼 무드 실사 CCTV 카메라 피드**: 단순 3D 와이어프레이머에 더해 고화질 실사 공간 스틸 베이스의 CCTV 모니터링 모드(`📸 REAL LIVE CCTV`)를 통합 지원합니다. 으스스한 지하 무균 격리소, 고요한 복도, 고위 원장의 방 등이 거친 그레이스케일 감시 카메라 감각으로 연출됩니다.
*   **3D 기하 벡터 분석 레이어 (`📐 3D VECTOR LAYER`)**: 고유 투시 투영 알고리즘(Perspective Projection matrix)을 탑재하여 언제든지 공학적 선형 벡터 모드로 상호 전환 가능합니다. 
*   **LED 손전등 광원 셰이더**: 마우스 좌표에 연계하여 가우시안 소프트 마스크 광원에 맞물려 어둠 속에 은닉된 핫스팟 노드들을 역동적으로 부각 및 발굴합니다.
*   **공간 맞춤형 가변 테마**: 현재 퀘스트의 지정 지리에 맞춰 '야간 본관 복도', '폐쇄 보건실', '원장 집무실', '지하 격리실' 등으로 3D 레이아웃 구조가 절차적으로 자동 재구축됩니다.

2.  **🎒 Reactive Gears & Organic Connection Analyzer**
*   "아이템을 많이 모았는데 어디다 써야 할지 영양가와 직결성이 크게 부족했다"라는 플레이어 피드백을 수용하여, **초대형 '소지품 유기적 연동 분석기' 섀시를 왼쪽 스크린 전체에 설계 반영**하였습니다.
*   **활성 결합 실시간 분석 (Active Coupling)**: 습득한 장비의 가상 시그널 작동 상황, 연동 예상 시점(예: 암호 교차 시점, 기계 물리 탈거 용도)을 실시간 가이드라인으로 전해줍니다.
*   **미해결 신호 지침 안내**: 획득하지 못한 미지의 암호화 지문들은 회수되지 않은 기밀 데이터 상태로 전개되어, 플레이어가 탐사 중 어떤 장소에서 단서를 취해 융합해야 하는지 구체적인 방향 지침을 제공합니다.

## 🗺️ 시나리오 분기 세부 매트릭스 (Story Matrices)

선택한 시나리오 구성에 따라 완전히 다른 기하학 구조와 퍼즐 해독 가치를 탐사하게 됩니다:

*   **시나리오 A (에덴의 가면)**: 심리적 스릴러와 극적인 서스펜스 위주. 'HILR' 암호 문자열을 역방향 4칸 복호화하여 문장 암호 `DONE`을 수득하고, 황수인과 김아란의 지하 승강기 대결 분지에서 갈라지는 전폭적 내적 신뢰를 측정합니다.
*   **시나리오 B (무균실의 기억)**: 본격 아날로그 전위 수치 암호 대항전. 영상 음향 모스부호 복원 `0047` 및 원서 기하 단순 누적 덧셈 배열화 `0014`, 책장 속 동일 도서 수량 컴퓨터 파킹 `0003` 등을 완벽히 결합한 최종 암호 `5047`을 투입해 탈취를 수립합니다.
*   **시나리오 C (선택받은 자들)**: 우성 적자 선별 기조의 학치적 잔혹극 고발 시스템. 비극적 낙오자 연합 학급 코드 `040723` 및 규리 갈색 매듭 팔찌의 수 결속 핀 다이얼 `747`, 유리 돔 표면의 긁힌 비극 날짜 일자 단순 정제 `0312`를 돌파해야 합니다.
